# Bolun Shika — Learn by Speaking

A responsive React + TypeScript learning workspace for conversational computer-science tutoring. The current build is a frontend demonstration: it uses local sample data and clearly labels simulated interactions.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
Copy-Item .env.example .env.local
npm run dev
```

In PowerShell, `Copy-Item` creates the local environment file. Set `VITE_API_BASE_URL` to the FastAPI origin when a backend is available. `VITE_DEMO_MODE=true` keeps tutoring on its isolated mock service; set it to `false` only when `/api/tutor/ask` is implemented. No credentials or provider keys belong in frontend environment variables.

## Routes

- `/` — Dashboard and sample weekly learning summary
- `/tutor` — Tutor chat, example prompts, browser speech input where supported, and browser speech playback
- `/resources` — Search/filter library and local PDF selection (PDF only, maximum 20 MB)
- `/practice` — Topic/difficulty quiz, answer checking, score, and explanations
- `/progress` — Calculated sample analytics and charts
- `/settings` — Validated preferences stored in this browser

## Demo behavior and backend boundary

Dashboard activity, learning metrics, resources, and quiz questions are bundled sample data, not account history. Tutor replies are illustrative demo text and are not generated by an LLM; no real source citations are fabricated. Browser speech is a convenience preview, not Gnani Prisma or Timbre. PDF selection and processing status are temporary UI state; files are not uploaded, indexed, or searchable. Preferences are stored locally in the browser.

The centralized API client is configured with `VITE_API_BASE_URL`. Typed service boundaries are prepared for:

- `POST /api/documents/upload`, `GET /api/documents`
- `POST /api/tutor/ask`, `POST /api/tutor/teach-back`
- `POST /api/voice/transcribe`, `POST /api/voice/synthesize`
- `POST /api/quiz/submit`
- `GET /api/progress/me`

The API boundaries do not imply those backend endpoints are running. Document, quiz, voice, and analytics screens remain in demo mode until connected intentionally.
